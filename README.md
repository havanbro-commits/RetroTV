# Tube TV · v0.3

Интерактивная комната середины 90-х: ламповый телевизор в нише стенки, июньский свет, тюль на окне, жизнь квартиры вокруг. Сцена — ваши готовые картинки; всё живое (экран, свет, звук, пасхалки) — слои поверх.

Чистые HTML/CSS/JS, без сборки и зависимостей.

```
index.html     разметка слоёв
style.css      стили, анимации подсказок, калибровка
main.js        вся логика: раскладка, ТВ-шейдер, свет, зоны, звук, события, калибровка
config.js      ВСЁ, что настраивается: зоны, каналы, громкости, интервалы, цвета, тексты
assets/        room-day.png, room-evening.png, curtain.png
assets/eggs/   вырезанные пасхалки и «чистые подложки» под ними (день и вечер)
assets/video/  ролики для видео-каналов (см. assets/video/README.md)
sounds/        файлы для подмены процедурных звуков (см. sounds/README.md)
```

## Запуск локально

Нужен любой локальный сервер (при открытии `index.html` двойным кликом браузер блокирует часть функций: файлы звуков, карту пылинок, цвет свечения от видео).

```bash
cd tube-tv
python3 -m http.server 8000
# или: npx serve .
```

Откройте http://localhost:8000.

## Деплой

**GitHub Pages.** Залейте папку в репозиторий → Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

**Netlify.** app.netlify.com → *Add new site* → *Deploy manually* → перетащите папку `tube-tv`. Или подключите репозиторий: build command — пусто, publish directory — `.`.

## Управление

| Действие | Как |
|---|---|
| Включить / выключить ТВ | кнопка внизу под динамиком (зона `power`) |
| Переключить канал | клик по верхней ручке; Shift+клик или правый клик — назад; колесо над ручкой |
| Громкость ТВ | колесо над нижней ручкой или потянуть её вверх/вниз |
| День → закат → вечер | клик по торшеру |
| Ясно → морось → ливень | клик по окну (шпингалет) |
| Звук целиком | кнопка в правом верхнем углу или клавиша M; ползунок «фон» — громкость фона отдельно от ТВ |
| Сесть перед телевизором | кнопка в правом верхнем углу, клавиша S или двойной клик по экрану; Esc — встать |
| Калибровка | клавиша D |

Первый клик по сайту включает весь звук (браузеры не дают звуку стартовать без действия пользователя).

## Калибровка зон (клавиша D)

1. Нажмите **D** — появятся рамки всех зон. Голубые — кликабельные, жёлтые — слои (экран, свечение, окно, мигалка, пылинки).
2. Тяните рамку, чтобы сдвинуть; уголок — изменить размер. Большие жёлтые слои тянутся за ярлык.
3. Точная подгонка: выберите зону, стрелки — сдвиг на 0.1% (Shift — 1%), Alt+стрелки — размер.
4. **«Скопировать конфиг»** — в буфер (и в поле на панели) попадёт блок `"zones": {...}`. Вставьте его в `config.js` вместо блока `zones`.

На панели калибровки есть кнопки для мгновенного запуска событий (сирена, яичница, часы, дверь, собака), переключения дня/вечера и ТВ.

## Каналы

Массив `channels` в `config.js`, порядок = порядок переключения. Типы:

- `testcard` — испытательная таблица с часами реального времени и тоном 1 кГц;
- `static` — помехи с шипением;
- `morning` — сгенерированная заставка утренней программы 90-х с музыкой и бегущей строкой (тексты — в конфиге);
- `video` — плейлист своих роликов (`playlist`), при каждом переключении на канал включается следующий ролик. Подробно — `assets/video/README.md`. Пока файлов нет, канал показывает синий экран «НЕТ СИГНАЛА».

Добавить канал — добавить объект в массив.

## Фон: видео вместо картинки

В `backgrounds` укажите `video: 'assets/room-day.mp4'` (и/или для вечера). Видео играет зацикленно, без звука, картинка служит постером. Если видео не указано или не загрузилось — используется картинка с покачиванием тюля (SVG-фильтр смещения только в зоне `window`).

## Звук

Всё генерируется процедурно через Web Audio API: тон комнаты, птицы и далёкие детские голоса днём, сверчки вечером, яичница за стеной, сирена с эффектом Доплера и панорамой слева направо, часы, хлопок двери в подъезде, собака, щелчки, звуки пасхалок и музыка утреннего канала.

Любой звук можно заменить файлом — см. `sounds/README.md`.

Случайные события: каждые 40–120 с (`events` в конфиге), одно и то же подряд не повторяется, яичница и сирена гарантированно звучат чаще, чем раз в 170 с.

## Доступность и производительность

- Анимируются только `transform` и `opacity`; экран рисуется одним WebGL-шейдером; цвет свечения на стене меняется через прозрачность трёх цветовых слоёв.
- `prefers-reduced-motion`: отключаются мерцание кинескопа, зерно и покачивание тюля, пылинки замедляются.
- Протестировано в Chrome; рассчитано на свежие Chrome и Safari (десктоп и мобильные).

## Отладка

В консоли доступен `TubeTV`: `TubeTV.Events.play('siren')`, `TubeTV.setMode('evening')`, `TubeTV.TV.toggle()`.

## Что нового в v0.2

- **Пасхалки двигаются в объёме.** Каждый предмет вырезан из картинки, под ним лежит дорисованный фон, поэтому при движении нет «двойника». Пакетик встряхивается и поворачивается к свету, тамагочи крутится на цепочке, брик-гейм поднимается экраном к вам и на нём падают кирпичики, мишка качается как неваляшка, у кассеты крутятся катушки, чайник дребезжит.
- **Кубик Рубика — настоящий 3D-куб** из 27 кубиков: появляется на месте фото, поворачивает две грани и возвращается.
- **Статуэтка вращается вокруг оси.** WebGL-шейдер натягивает фото на поверхность вращения по силуэту статуэтки; бока и спина дорисовываются как фарфор с бликом и складками. Это иллюзия из одного снимка: с настоящей 3D-моделью (.glb) спина была бы точной.
- **Тюль без шва.** Волна ходит туда-обратно с плавным разворотом, петля больше не «перескакивает».
- **Яичница слышна из кухни.** Плотный треск масла, пропущенный через «стену» (срез верхов выше ~1,7 кГц), короткое эхо кухни, глухие стуки лопатки.
- **«Сесть перед телевизором».** Камера плавно наезжает, телевизор занимает ~80% экрана, края темнеют; экран перерисовывается в повышенном разрешении.
- **Плейлисты на видео-каналах**: новый ролик при каждом переключении, режимы по порядку / случайно / «живой эфир».

Вырезки в `assets/eggs/` сделаны под текущие `room-day.png` и `room-evening.png`. Если перегенерируете сцену, их нужно вырезать заново.

## Что нового в v0.3

- **YouTube-каналы «Старого телевизора».** Два канала в `channels` играют случайные ролики из загрузок YouTube-каналов staroetv через официальный встраиваемый плеер (`youtube-nocookie.com`), с случайного места, как будто эфир шёл без вас. Громкость — с ручки телевизора. Плеер лежит «под стеклом»: строки развёртки, теневая маска, виньетка, отражение комнаты, мерцание; включение/выключение и помехи — общие для всех каналов. Полного шейдерного кинескопа здесь нет: браузер не отдаёт пиксели чужого плеера.
  - Работает на GitHub Pages / Netlify / localhost. В превью на claude.ai встраивание чужих сайтов запрещено — там канал покажет «YouTube недоступен».
  - Если владелец отключил встраивание ролика, плеер сам перескочит на следующий.
- **Пасхалки без двойников.** Подложки под предметами перерисованы алгоритмом восстановления текстуры (раньше там оставался размытый силуэт). Кубик вырезан целиком с боковой гранью. Подсветка наведения гаснет на время анимации.
- **Ветер.** Тюль дышит постоянно, а раз в 7–18 секунд приходит порыв: нарастает 1–2 с, держится, стихает 3–5 с; подол чуть приподнимается. Порывы слышны (гул и шелест в окне) и сносят пылинки. В дождь ветер сильнее. Всё настраивается в `wind`.
- **Пыль «как споры».** Три слоя глубины, медленный дрейф во все стороны по вихревому полю, ярче в лучах света, ближние — крупным размытым боке. Количество — `light.spores`.
- **Мигалка сквозь тюль.** Свет проходит через узор кружева (текстура из `curtain.png`) и ложится на всю комнату, бежит по стене в обратную сторону, а на самом тюле — по ходу машины. Машины реже: не чаще раза в 5 минут гарантированно, иначе по весу.
- **Закат** — третий режим торшера (своя картинка, стрижи, свет теплее).
- **Погода по клику на окно:** ясно → морось → ливень. Пасмурная сцена, капли за стеклом, звуки дождя, капли по отливу, водосток, в ливень — молнии и гром.
- **Яичница** — ваши два файла, случайно, через «стену» кухни (`audio.kitchenCutoff`).
- **Далёкая собака** во дворе — редко, с эхом между домами.
- **Чёткий телевизор в режиме «сесть».** Корпус и ниша увеличены нейросетью Real-ESRGAN ×4 (`assets/hires/`) и подгружаются при наезде.

Картинки `room-sunset.png` и `room-overcast.png` собраны цветокоррекцией из ваших дневной и вечерней. Если сгенерируете свои с той же композицией — просто замените файлы (и при желании пересоберу вырезки пасхалок и `assets/hires/`).
