# Видео для каналов

Положите сюда ролики (mp4 / H.264 — играет везде, включая Safari на iPhone) и перечислите их
в `config.js` → `channels` → `playlist` нужного канала:

```js
{ type: 'video', label: 'AV-1', order: 'sequence', live: false,
  playlist: ['assets/video/ch4-01.mp4', 'assets/video/ch4-02.mp4'] },
```

- `order: 'sequence'` — по порядку, `'shuffle'` — случайно, без повтора подряд.
- Каждое переключение на канал включает следующий ролик; закончился ролик — сам начинается следующий.
- `live: true` — ролик стартует с середины, как будто эфир шёл без вас.
- Видео 16:9 автоматически получает чёрные полосы сверху и снизу, 4:3 занимает весь экран.
- Звук роликов идёт через ручку громкости телевизора.

Совет: для веса страницы ужмите ролики до 480p, ~1 Мбит/с:
`ffmpeg -i in.mp4 -vf scale=-2:480 -c:v libx264 -crf 28 -preset slow -c:a aac -b:a 96k -movflags +faststart out.mp4`

Берите ролики, на которые у вас есть права (свои записи, архивы с открытой лицензией,
материалы, разрешённые правообладателем).
