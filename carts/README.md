# Картриджи Tube TV

Три собственные игры для Mega Drive / Genesis, написанные для сайта:

| Файл | Игра |
|---|---|
| `snake.bin` | «Змейка» — двор, яблоки и золотая груша |
| `bricks.bin` | «Кирпичики» — выбей все кирпичи |
| `patrol.bin` | «Звёздный патруль» — защити двор от тарелок; вдвоём (второй геймпад — Start) |

Исходники — в `src/` (C + SGDK, графика рисуется скриптами `art.py` из текста).
Сборка: `SGDK=/путь/к/SGDK ./src/build.sh snake snake.bin` (нужны `m68k-linux-gnu-gcc`, python3 и Pillow).

Шрифт — Press Start 2P (SIL Open Font License, `src/tools/fonts/OFL-PressStart2P.txt`).
SGDK — MIT. Игры и их графика — собственные, коммерческих ROM в репозитории нет.

Свои картриджи можно запускать на сайте: меню приставки → «Свой картридж…» (или перетащить файл на страницу).
Файл не покидает браузер.
