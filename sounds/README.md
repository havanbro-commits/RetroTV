# Свои звуки

По умолчанию все звуки генерируются процедурно. Чтобы заменить любой из них файлом:

1. Положите файл в эту папку (mp3, ogg, wav, m4a — что понимает браузер).
2. В `config.js` → `audio.files` впишите путь вместо `null`, например:
   `'siren': 'sounds/siren.mp3'`.

Или назовите файлы ровно как в списке ниже (`<имя>.mp3`) и включите `audio.autoDetectFiles: true` — сайт найдёт их сам.

| Имя | Что это | Тип |
|---|---|---|
| `room-tone` | тихий фон комнаты | петля |
| `street-day` | дневная улица за окном | петля |
| `birds` | птицы | петля |
| `children` | далёкие детские голоса | петля |
| `street-evening` | вечерний гул | петля |
| `crickets` | сверчки | петля |
| `frying` | яичница — проигрывается «через стену» кухни; можно массив файлов | событие |
| `siren` | машина с сиреной (панорама и громкость накладываются сверху, отблески подстроятся под длину файла) | событие |
| `clock` | тиканье часов | событие |
| `door` | хлопок двери в подъезде | событие |
| `dog` | лай собаки | событие |
| `dog-far` | собака далеко во дворе | событие |
| `thunder` | гром (в ливень) | событие |
| `street-sunset`, `swifts` | улица и стрижи на закате | петля |
| `rain-light`, `rain-heavy` | морось и ливень | петля |
| `window-latch` | шпингалет окна | разово |
| `tv-on`, `tv-off` | щелчок включения / выключения | разово |
| `channel-click` | щелчок переключателя каналов | разово |
| `tv-testcard`, `tv-static`, `tv-morning` | звук каналов (идёт через громкость ТВ) | петля |
| `lamp-click` | выключатель торшера | разово |
| `egg-sachet`, `egg-tamagotchi`, `egg-brickgame`, `egg-rubik`, `egg-bear`, `egg-cassette`, `egg-figurine`, `egg-teapot` | пасхалки | разово |

Петли зацикливаются автоматически — делайте их с бесшовным стыком.
