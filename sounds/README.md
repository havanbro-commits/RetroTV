# Звуки Tube TV

Часть звуков — файлы из этой папки, остальное синтезируется прямо в браузере (Web Audio).
Любой процедурный звук можно заменить файлом: положите его сюда и впишите путь в `config.js` → `audio.files`
(массив путей — каждый раз случайный вариант). Петли зацикливаются сами.

## Окно

Окно — не фильтр, а модель пространства. Открыто — каждый уличный звук приходит со своего места во дворе
(HRTF для наушников) с отражениями от домов. Закрыто — двойные рамы пропускают в основном низ, немного
«воздуха» сквозь щели, улица звучит уже из плоскости окна, а доля отзвука комнаты растёт.
Капли по стеклу и отливу остаются, но глуше. Створка двигается плавно — колёсико мыши над шторой.

## Процедурные звуки (можно заменить файлом)

| Имя | Что это | Тип |
|---|---|---|
| `room-tone` | тихий фон комнаты | петля |
| `street-day`, `birds`, `children` | дневная улица, птицы, детские голоса | петля |
| `street-sunset`, `swifts` | улица и стрижи на закате | петля |
| `street-evening`, `crickets` | вечерний гул, сверчки | петля |
| `siren`, `door` | сирена, дверь в подъезде | событие |
| `window-latch`, `lamp-click` | шпингалет окна, выключатель торшера | разово |
| `tv-on`, `tv-off`, `channel-click` | включение, выключение, щелчок тумблера каналов | разово |
| `tv-testcard`, `tv-static`, `tv-morning` | звук каналов (через динамик телевизора) | петля |
| `egg-deer`, `egg-brickgame`, `egg-rubik`, `egg-bear`, `egg-cassette`, `egg-figurine`, `egg-teapot` | пасхалки | разово |

Звук приставки идёт в динамик телевизора — его громкость и тембр те же, что у эфира.
